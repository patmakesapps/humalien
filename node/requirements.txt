# The eyes. Provides `adafruit_raspberry_pi5_neopixel_write`, which is the
# only path that works on a Pi 5 - the RP1 has no PWM/DMA route the older
# rpi_ws281x libraries can use, so it drives the pixels over PIO instead.
#
# TWO THINGS THIS NEEDS BEYOND pip install:
#
#   1. /dev/pio0 must exist and be reachable without root. If it is owned
#      root:root, add to /etc/udev/rules.d/99-com.rules:
#
#          SUBSYSTEM=="*-pio", GROUP="gpio", MODE="0660"
#
#      then reboot. If the file is missing entirely, the Pi 5 firmware is
#      too old for PIO support. Without this the node logs
#      "No NeoPixels, running blind-faced" and keeps its voice.
#
#   2. LICENCE: this package is GPL-2.0-only, unlike everything else here.
#      It is an import, not vendored source, but Humalien may become a commercial
#      product and shipping an image containing it carries obligations the
#      other dependencies do not. Flagged deliberately - see the note in
#      node/NEOPIXEL_MAP.md before this ships on hardware that leaves the
#      building.
adafruit-blinka-raspberry-pi5-neopixel==1.0.0rc2
